# Переводчик выделенного текста (Python)

Приложение для перевода выделенного текста с помощью горячей клавиши.

## Возможности

- Перевод выделенного текста в любом приложении по горячей клавише
- Выбор языков перевода (с какого на какой)
- Настройка горячей клавиши
- Отображение перевода во всплывающем окне рядом с курсором
- Нажатие горячей клавиши повторно скрывает окно перевода
- Перевод текста из буфера обмена
- Сворачивание в трей
- Автоматический запуск (опционально)

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Или запустите `run.bat`

## Использование

1. Запустите приложение
2. Выберите языки перевода в настройках
3. Настройте горячую клавишу (по умолчанию Ctrl+Alt+T)
4. Выделите текст в любом приложении и нажмите горячую клавишу
5. Рядом с курсором появится окно с переводом
6. Нажмите горячую клавишу ещё раз, чтобы скрыть окно перевода
